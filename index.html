پنل اتصال و مدیریت ربات روبیکا

🔐 اتصال ربات

توکن ربات را وارد کن تا اطلاعاتی که API ارائه می‌دهد دریافت شود. توکن در حافظه موقت این صفحه نگهداری می‌شود.

وضعیت: هنوز متصل نشده است.

📋 پاسخ API

اگر اطلاعات ربات نمایش داده نشد، این قسمت به تشخیص مشکل اتصال کمک می‌کند. توکن در گزارش نمایش داده نمی‌شود. 

هنوز پاسخی دریافت نشده است.

🛡️ حفظ امنیت

توکن را فقط در سایت مورد اعتمادت وارد کن. این صفحه توکن را در localStorage یا sessionStorage ذخیره نمی‌کند و کدی برای ارسال توکن به صاحب سایت ندارد. با بستن صفحه، متغیر توکن از بین می‌رود.

درخواست API برای احراز هویت مستقیماً به روبیکا ارسال می‌شود. اگر مرورگر درخواست را به دلیل CORS مسدود کند، اتصال مستقیم از این صفحه امکان‌پذیر نخواهد بود.
